## 卧推

### 杠铃卧推（各分化通用）

卧推不是"躺下推起来"这么简单。几个关键点：

- 肩胛骨全程收紧（想象肩胛骨中间夹着一张纸）
- 杠铃下放到底的位置在**下胸附近**，不是锁骨
- 底部停顿一下再推，不要靠弹性反弹

### 水牛杆卧推

如果你肩关节柔韧性不太好，或者卧推卡在平台期，可以试试水牛杆。

王正浩（自强不息归来）推荐水牛杆的理由：
- 杆的弧度让手臂在低位时更舒服，对肩关节压力小
- 行程更稳定，动作轨迹更可控
- 适合卡平台期或想要换刺激的训练者

不过需要注意的是，有研究表明在 1RM 测试中，直杆的胸肌激活程度略高于水牛杆。
所以水牛杆可以作为阶段性变式工具，不一定要替代直杆。

## 硬拉器硬拉（你的常用动作）

这是你当前腿日的硬拉类主项，从数据看峰值到过 160kg，近期回落到 80-120kg 左右。

如果你想要恢复到这个水平：
1. 先从 80kg × 8 做 4 组起步（RPE 7 左右的感受）
2. 每周加一点——要么加 2.5-5kg，要么每次多做 1-2 次
3. 当你能用 100kg × 8 做 4 组时，算恢复到合理水平了

硬拉类动作最怕的就是急着加重。不要看以前做过多重，看今天状态。

## 动作替代速查

什么器械没有的时候，可以用什么代替：

| 想练的部位 | 首选动作 | 如果做不了/不想做 |
|------------|----------|------------------|
| 胸 | 杠铃卧推 | 哑铃卧推、器械推胸 |
| 背（宽度） | 引体向上 | 高位下拉 |
| 背（厚度） | 坐姿划船 | 哑铃划船、器械划船 |
| 肩前束 | 杠铃推举 | 器械推肩、哑铃推肩 |
| 肩后束 | 面拉 | 反向飞鸟 |
| 手臂（二头） | 器械弯举 | 哑铃弯举、绳索弯举 |
| 手臂（三头） | 绳索臂屈伸 | 窄距卧推、双杠臂屈伸 |
| 大腿前侧 | 杠铃深蹲 | 保加利亚蹲、腿举 |
| 大腿后侧 | 硬拉器硬拉 | 腿弯举、罗马尼亚硬拉 |

## 关于腿部动作（结合你的偏好）

你之前说过腿部动作处于技术打磨期，短期内用小重量中次数。
这是很合理的选择——腿部动作技术门槛高，大重量之下动作容易变形。

建议在这个阶段加入的动作（选 1-2 个补充到你的腿日）：

1. **哑铃保加利亚蹲** — 单侧训练，能暴露左右不平衡，同时锻炼稳定性。
   从每只手 10-16kg 起步，8-12 rep，专注控制膝盖方向和身体稳定。

2. **哑铃箭步蹲（反向）** — 你之前做过，对股四头肌和臀部刺激很好。
   保持轻重量，10-12 rep，主要练动作模式。

3. **腿举** — 机器安全，适合在不担心平衡的前提下积累股四容量。
   可以放到 12-15 rep，专注肌肉收缩感受。

## 一次训练的动作组织

```
主项（复合）  →  你最看重进步的动作，放在最前面
辅助（复合）  →  另一个复合动作，换一个角度
辅助（单关节）→  针对弱点的小动作
收尾          →  高次数让肌肉充血
```

一次训练一般不超 5 个动作，太多动作会导致主项的组数不够。
