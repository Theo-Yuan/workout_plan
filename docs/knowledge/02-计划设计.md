# 计划设计

什么样的训练计划算好计划？满足三条：
1. **能坚持**——频率和时长适合你的生活节奏
2. **有渐进**——每次训练都在前一次的基础上加一点
3. **可恢复**——练完有足够的时间恢复，不影响下一次

---

## 第一步：选分化

选择哪个分化方案，主要看**你每周能去几次**。

### 如果你每周能去 3 天 → 全身训练
每次练全身，每个肌群都练到。适合时间有限的人。
- 每肌群频率高（每周 3 次），增肌效果好
- 不需要纠结今天练什么

### 如果你每周能去 4 天 → 上下肢分化
上肢日 + 下肢日交替。适合大多数中级训练者。
- 每个肌群每周练 2 次，频率刚好
- 恢复时间充足（上肢日之后是下肢日，交替进行）

### 如果你每周能去 5-6 天 → PPL 推拉腿 ← 你当前在用
推日（胸+肩+三头）、拉日（背+二头）、腿日（股四+腘绳+臀）。
这是目前最流行的进阶方案，也是**自然训练者的最优选择**。
[来源: S2-自然训练理念]

好处是每个部位一周能练 2 次，每次只专注 2-3 个肌群，效率很高。

### 不推荐：传统健美分化
每天只练一个部位（周一胸、周二背、周三肩……）。
每个肌群每周只练 1 次，对自然训练者频率太低。
[来源: S1-训练分化]｜[参考: 训练编排与分化方案](https://simonhancrew.github.io/posts/2026-05-13-training-split-programming/)

## 第二步：套周期化

周期化就是把一年的训练分成几个阶段，每个阶段有不同的重点。

**周期化比没周期化多增长约 22% 的力量，对卧推尤其明显（快 55%）。**
[来源: S1-周期化](https://www.strongerbyscience.com/periodization-data-cn/)

### 常见的几种周期化方式

**线性周期化（适合新手）**
从一个阶段过渡到下一个，不回头：
```
增肌期（4-6周）→ 力量期（4-6周）→ 峰值期（2-3周）→ 减载（1周）
```

**每日波动周期化 DUP（适合中级以上）**
在同一次训练的不同动作上使用不同次数范围。
例如推日：先做 5×5 的大重量复合动作，再做 3×10-12 的辅助动作。
这样一天之内既有力量刺激又有增肌刺激，效率很高。
[来源: S1-训练分化]

**块状周期化（适合高级/备赛）**
分成几个"块"，每个块 3-4 周：
- 累积块：大量中等重量训练
- 转化块：容量减少、重量增加
- 实现块：轻量高频、保持状态

## 第三步：填充动作

主项放在训练前段，辅助动作放在后段。

### 一次训练的模板

```
1. 主项 1（复合动作） × 3-4 组，6-10 rep，RPE 7-9
2. 主项 2（复合动作） × 3-4 组，8-12 rep，RPE 7-9
3. 辅助动作 1 × 3 组，10-15 rep，RPE 7-8
4. 辅助动作 2 × 3 组，10-15 rep，RPE 7-8
5. （可选）收尾动作 × 2-3 组，12-15 rep
```

### PPL 各日动作参考

**推日（Push）** — 水平推 + 垂直推 + 侧举 + 三头

```
主项：杠铃卧推（水平推） or 器械坐姿推举（垂直推）
辅助：哑铃推肩、绳索侧平举、双杠臂屈伸
收尾：绳索臂屈伸
```

**拉日（Pull）** — 水平拉 + 垂直拉 + 后束 + 二头

```
主项：坐姿划船（水平拉）or 引体向上/高位下拉（垂直拉）
辅助：哑铃划船、面拉、器械弯举
```

**腿日（Legs）** — 膝主导 + 髋主导 + 腹部

```
主项：深蹲变形（膝主导）or 硬拉变形（髋主导）
辅助：腿举、保加利亚蹲、悬挂抬腿
```

动作选择参考训记标准动作名表：
https://github.com/Foveluy/Xunji-movements

## 附：关于你的计划

你当前在执行的「腿推拉·6练」（Platform:70）是 PPL 的合理实现。
从近 3 个月的数据看，你每周的实际频率是 4-5 次。

如果你觉得腿日恢复不过来，可以：
1. 每周 4 练：推→拉→腿→推（多一次推来强化胸肩）
2. 每周 5 练：推→拉→腿→推→拉（均匀分配）
3. 腿日把动作从 3-4 个减到 2 个，把总量控制在你可恢复的范围内

具体怎么调，取决于你的恢复感受。
