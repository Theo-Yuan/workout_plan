## 卧推

### 杠铃卧推（各分化通用）

卧推不是"躺下推起来"这么简单。几个关键点：

- 肩胛骨全程收紧（想象肩胛骨中间夹着一张纸）
- 杠铃下放到底的位置在**下胸附近**，不是锁骨
- 底部停顿一下再推，不要靠弹性反弹

### 水牛杆卧推

如果你肩关节柔韧性不太好，或者卧推卡在平台期，可以试试水牛杆。

王正浩（自强不息归来）推荐水牛杆的理由：
- 杆的弧度让手臂在低位时更舒服，对肩关节压力小
- 行程更稳定，动作轨迹更可控
- 适合卡平台期或想要换刺激的训练者

不过需要注意的是，有研究表明在 1RM 测试中，直杆的胸肌激活程度略高于水牛杆。
所以水牛杆可以作为阶段性变式工具，不一定要替代直杆。

## 硬拉类动作

硬拉类动作最怕的就是急着加重。恢复或进步的策略：
1. 从一个舒适重量 × 8 做 4 组起步（RPE 7 左右）
2. 每周加一点——加重量或加次数，不同时加
3. 连续 2 次训练稳定完成后，再考虑下一次进阶

## 动作替代速查

什么器械没有的时候，可以用什么代替：

| 想练的部位 | 首选动作 | 如果做不了/不想做 |
|------------|----------|------------------|
| 胸 | 杠铃卧推 | 哑铃卧推、器械推胸 |
| 背（宽度） | 引体向上 | 高位下拉 |
| 背（厚度） | 坐姿划船 | 哑铃划船、器械划船 |
| 肩前束 | 杠铃推举 | 器械推肩、哑铃推肩 |
| 肩后束 | 面拉 | 反向飞鸟 |
| 手臂（二头） | 器械弯举 | 哑铃弯举、绳索弯举 |
| 手臂（三头） | 绳索臂屈伸 | 窄距卧推、双杠臂屈伸 |
| 大腿前侧 | 杠铃深蹲 | 保加利亚蹲、腿举 |
| 大腿后侧 | 硬拉器硬拉 | 腿弯举、罗马尼亚硬拉 |

## 关于腿部动作打磨期

腿部动作技术门槛高，大重量之下动作容易变形。
技术打磨期用小重量中次数（10-15 rep）是很合理的选择。

推荐的打磨期动作：
1. **哑铃保加利亚蹲** — 单侧训练，暴露左右不平衡，锻炼稳定性
2. **哑铃箭步蹲（反向）** — 股四头肌和臀部刺激好，动作模式价值高
3. **腿举** — 机器安全，适合在不担心平衡的前提下积累股四容量

## 一次训练的动作组织

```
主项（复合）  →  你最看重进步的动作，放在最前面
辅助（复合）  →  另一个复合动作，换一个角度
辅助（单关节）→  针对弱点的小动作
收尾          →  高次数让肌肉充血
```

一次训练一般不超 5 个动作，太多动作会导致主项的组数不够。
